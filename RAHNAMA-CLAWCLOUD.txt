  راهنمای کامل نصب ربات بازنشر روی سرور رایگان ClawCloud Run
  (کانتینر ۲۴/۷ واقعی — بدون خواب — بدون کارت بانکی)
══════════════════════════════════════════════════════════════

چرا این سرور؟
  • هر ماه ۵ دلار اعتبار رایگان می‌دهد — برای ربات ما (~۳ دلار در ماه)
    بیش از حد کافی است؛ یعنی «رایگان برای همیشه»
  • هیچ‌وقت نمی‌خوابد، ری‌استارت خودکار دارد، حجم پایدار (دیتابیس
    ضدتکرار با ری‌استارت پاک نمی‌شود)
  • همه‌چیز با مرورگر — نه CMD می‌خواهد نه ترمینال
  • ثبت‌نام با گیت‌هاب است و کارت بانکی نمی‌خواهد

⚠️ تنها شرطش: یک اکانت گیت‌هاب با حداقل ۶ ماه قدمت (بخش گام ۰)

────────────────────────────────────────────
گام ۰) چک کردن سن اکانت گیت‌هاب (مهم‌ترین شرط!)
────────────────────────────────────────────
۱. برو به github.com و لاگین کن
۲. روی عکس پروفایلت کلیک کن → در صفحهٔ پروفایل سمت چپ نوشته:
   «Joined MMM DD, YYYY» (تاریخ عضویت)
۳. اگر بیش از ۶ ماه (۱۸۰ روز) پیش بود → همه‌چیز آماده است، برو گام ۱
۴. اگر اکانت نداری یا جدید است:
   • اعتبار ۵ دلاری فقط «یک ماه» می‌شود، ماه بعد تمدید نمی‌شود
   • در این حالت دو راه داری:
     الف) همین حالا اکانت گیت‌هاب بساز، ۶ ماه صبر کن و فعلاً ربات را
          روی Hugging Face نگه دار (همان Space قبلی + رشتهٔ گوشی)
     ب) یا بگو تا برایت گزینهٔ دیگری آماده کنم

────────────────────────────────────────────
گام ۱) ساختن مخزن (Repository) در گیت‌هاب
────────────────────────────────────────────
۱. در github.com بالای صفحه: +  ←  New repository
۲. Repository name:  telegetter-bot
۳. Public را انتخاب کن (برای بیلد رایگان لازم است؛ هیچ رمزی داخل
   این فایل‌ها نیست، نگران نباش)
۴. دکمهٔ «Create repository» را بزن

────────────────────────────────────────────
گام ۲) آپلود فایل‌های ربات
────────────────────────────────────────────
۱. اول فایل zip را از حالت فشرده خارج کن (راست‌کلیک → Extract All)
۲. در صفحهٔ ریپوی تازه‌ساخته روی لینک
   «uploading an existing file» کلیک کن
۳. «محتویات» پوشهٔ telegram-reposter-clawcloud را انتخاب و بکش و
   توی صفحهٔ آپلود رها کن — یعنی همهٔ فایل‌ها و پوشه‌های داخلش،
   شامل پوشهٔ .github (اگر پوشه‌های مخفی دیده نمی‌شوند، در Explorer
   از منوی View گزینهٔ Hidden items را روشن کن)
۴. صبر کن بنویسد همه فایل‌ها اضافه شدند (باید ~۱۲ فایل باشد)
۵. پایین صفحه دکمهٔ «Commit changes» را بزن

💡 راه جایگزین برای پوشهٔ .github (اگر درگ شدنی جواب نداد):
   در ریپو: Add file ← Create new file ← در قسمت اسم فایل دقیقاً
   تایپ کن:  .github/workflows/docker-publish.yml
   بعد محتوای فایل docker-publish.yml را از داخل پکیج کپی کن داخلش
   و Commit کن.

────────────────────────────────────────────
گام ۳) بیلد خودکار تصویر (Actions)
────────────────────────────────────────────
۱. در ریپو برو به تب «Actions»
۲. یک کار به اسم «Build and push Docker image» در حال اجراست —
   ۱ تا ۲ دقیقه صبر کن تا دایره‌اش «✓ سبز» شود
3. اگر «✗ قرمز» شد، روش کلیک کن و متن ارور را برایم کپی و بفرست

────────────────────────────────────────────
گام ۴) عمومی‌کردن بستهٔ ساخته‌شده (خیلی مهم!)
────────────────────────────────────────────
۱. روی عکس پروفایل ← «Your packages»
2. بستهٔ telegetter-bot را باز کن
3. پایین صفحه: «Package settings»
4. پایین‌ترین قسمت (Danger Zone): «Change visibility»
5. «Public» را انتخاب کن و برای تأیید اسم بسته را تایپ کن
   ← اگر این مرحله را نزنی، سرور نمی‌تواند بسته را بکشد بیرون!

اسم کامل تصویر تو این است (دقیقاً همین، همه حروف کوچک):
   ghcr.io/YOUR_GITHUB_USERNAME/telegetter-bot:latest
(YOUR_GITHUB_USERNAME را با یوزرنیم گیت‌هابت عوض کن)

────────────────────────────────────────────
گام ۵) ثبت‌نام ClawCloud
────────────────────────────────────────────
1. برو به:  https://run.claw.cloud
2. «Get Started for Free» ← «Sign in with GitHub» ← Authorize
3. یک Region (منطقه) ازت می‌پرسد — هر کدام را راحت‌تری انتخاب کن
   (پیشنهاد: Japan/Tokyo)
4. وارد Console می‌شوی. بالا/داخل صفحه نوشته Credit: $5.00
   ← اگر 0 بود یعنی گیت‌هابت به ۱۸۰ روز نرسیده (برو گام ۰)

────────────────────────────────────────────
گام ۶) ساختن اپلیکیشن ربات (App Launchpad)
────────────────────────────────────────────
1. از منو: App Launchpad ← «Create Application»
2. فیلدها را دقیقاً این‌طوری پر کن:

   Application Name:  telegetter
   Image:  Public  ← ghcr.io/YOUR_GITHUB_USERNAME/telegetter-bot:latest
   Replicas:  1
   CPU:  0.3      Memory:  512  (M)

   Network:
      Container Port: 8080     Public Access: ✅ روشن کن
      (یک لینک عمومی بهت می‌دهد — برای چک سلامت ربات است)

   Advanced  ←  Environment Variables:  یک ردیف اضافه کن:
      Key:   SESSION_STRING
      Value: (فعلاً خالی — در گام ۸ می‌گذاریمش)

   Advanced  ←  Local Storage (حجم پایدار — خیلی مهم!):
      Capacity: 1     Mount Path: /app/data

   Advanced  ←  Restart Policy: Always (اگر داشت)

3. «Deploy» را بزن

💡 چرا Local Storage؟ دیتابیس ضدتکرار و لاگ‌ها باید با ری‌استارت‌ها
   باقی بمانند. اگر این را نگذاری، هر ری‌استارت تاریخچه پاک می‌شود
   (هرچند بکاپ ۶ ساعته در Saved Messages همچنان کمکت می‌کند).

────────────────────────────────────────────
گام ۷) ساختن کلید نشست با «گوشی» (Termux)
────────────────────────────────────────────
چرا گوشی؟ چون نشست از IP خانه‌ی خودت متولد می‌شود؛ تلگرام می‌فهمد
که این ورود از خودِ خانه و خودِ گوشی توست و دستگاه‌هایت را بیرون
نمی‌اندازد. (متولدشدن نشست روی سرور ابری همان بود که قبلاً همه را
لاگ‌اوت کرد — دیگر هرگز این کار را نکن.)

۱. Termux را از F-Droid یا گیت‌هاب نصب کن (نسخهٔ Play Store قدیمی است):
      https://f-droid.org/packages/com.termux/
۲. فیلترشکن گوشی را روشن کن (حالت تونل/VPN)
۳. در Termux این خط را پیست کن و اینتر بزن (۲-۳ دقیقه طول می‌کشد):

   pkg update -y && pkg install python -y && pip install telethon

۴. حالا این خط را پیست کن و اینتر بزن:

   printf 'from telethon.sync import TelegramClient\nfrom telethon.sessions import StringSession\nc = TelegramClient(StringSession(), 6, "eb06d4abfb49dc3eeb1aeb98ae0f581e")\nc.start()\ns = c.session.save()\nopen("session.txt", "w").write(s)\nprint()\nprint("SESSION STRING - copy the next line:")\nprint(s)\n' > login.py && python login.py

۵. ازت شماره می‌پرسد: با فرمت بین‌المللی بزن:  +989123456789
   کد ۵ رقمی که به خودت پیام می‌شود را بزن (از داخل تلگرام خودت می‌آید)
   اگر پسورد دوم‌مرحله‌ای (2FA) داری، آن را هم بزن
۶. رشته‌ای چاپ می‌شود (۳۵۳ کاراکتر). همچنین در فایل session.txt ذخیره شده.
۷. برای راحت‌تر کپی‌کردن، این دو خط را هم بزن:
      termux-setup-storage      (اجازهٔ دسترسی را Accept کن)
      cp session.txt ~/storage/downloads/
   بعد در اپ Files گوشی ← پوشهٔ Download ← فایل session.txt را با
   یک اپ متن‌باز کن، Select All و Copy کن.

⚠️ هشدارهای مهم:
  • این رشته مثل پسورد اکانتت است! فقط در گام ۸ روی سرور بگذارش و
    هیچ‌جای دیگر پیست نکن (نه ریپوی گیت‌هاب، نه هیچ چت و گروهی)
  • تلگرام یک اعلان «New login: Telegram Android» می‌دهد — طبیعی است
  • در Settings ← Devices آن نشست جدید را terminate نکن! همان رشتهٔ
    ربات است و حذفش = مرگ ربات
  • کد ۵ رقمی را به «هیچ‌کس» — حتی کسی که ادعای پشتیبانی می‌کند — نده

────────────────────────────────────────────
گام ۸) گذاشتن رشته در اپلیکیشن
────────────────────────────────────────────
1. در ClawCloud، اپلیکیشن telegetter را باز کن
2. از منوی اپ (سمت چپ): Advanced ← Environment Variables
3. ردیف SESSION_STRING را پیدا کن (یا جدید بساز) و در Value رشتهٔ
   ۳۵۳ کاراکتری را پیست کن (بدون گیومه، بدون فاصله اضافه)
4. تأیید و ذخیره کن ← اپلیکیشن خودش ری‌استارت می‌شود

────────────────────────────────────────────
گام ۹) چک نهایی و راه‌اندازی داخل تلگرام
────────────────────────────────────────────
1. در اپ telegetter ← منوی Logs را باز کن. باید بعد چند ثانیه ببینی:

      ✅ Reposter bot is running!
      👤 Account:  اسم تو (@username)

2. حالا در تلگرام گوشی، به «پیام‌های ذخیره‌شده» (Saved Messages) برو
   و دستورها را بزن:

      /help                 ← لیست همهٔ دستورها
      /setdest @mychannel   ← کانال مقصد (کانی که خودت سازنده‌اش هستی)
      /test                 ← پست آزمایشی در مقصد
      /add @sourcechannel   ← اضافه‌کردن کانال منبع
      /list                 ← لیست منابع

تمام! ربات ۲۴/۷ روشن می‌ماند؛ نه UptimeRobot می‌خواهد نه نگهداری.

────────────────────────────────────────────
عیب‌یابی
────────────────────────────────────────────
• در ClawCloud ارور «ImagePullBackOff» یا «Failed to pull image»
  → گام ۴ را کامل نکرده‌ای (بسته هنوز Private است) یا اسم تصویر را
  اشتباه نوشته‌ای (باید همه حروف کوچک باشد و با ghcr.io شروع شود)

• اپ مدام ری‌استارت می‌شود (CrashLoop)
  → لاگ‌ها را باز کن؛ اگر نوشت SESSION_STRING is not set → گام ۸
  → اگر ارور corrupted → رشته ناقص کپی شده؛ گام ۸ را از اول

• تب Actions در گیت‌هاب قرمز شد
  → معمولاً فایل workflow در مسیر اشتباه است؛ باید باشد:
     .github/workflows/docker-publish.yml

• «The key is not registered in the system» در لاگ‌ها
  → تلگرام آن نشست را باطل کرده. ترتیب درست:
    ۱) در گوشی: Settings ← Privacy and Security ← Two-Step
       Verification ← Change password (پسورد را عوض کن)
    ۲) دوباره گام ۷ (رشتهٔ تازه) و گام ۸

• «همهٔ دستگاه‌هایم از تلگرام بیرون انداخته شدند»
  → یعنی جایی یک ورودِ جدیدِ غیر از روش گوشی انجام شده. هیچ‌وقت
    Reset account نزن! با ایمیل بازیابی برگرد و فقط از روش Termux
    استفاده کن

────────────────────────────────────────────
هزینه و نگهداری
────────────────────────────────────────────
• با تنظیم پیشنهادی (0.3 CPU / 512MB / 1GB دیسک) مصرف ماهانه حدود
  ۲ تا ۳.۵ دلار است — از اعتبار ۵ دلاری جا می‌شوی
• ماهی یک بار به Billing نگاه کن؛ اگر مصرف داشت به سقف نزدیک می‌شد
  بگو تا تنظیمات را جمع‌وجورتر کنم
• هرگز فایل .env یا رشتهٔ نشست را داخل ریپوی گیت‌هاب نگذار — رشته
  فقط در Environment Variables کلادکلاد زندگی می‌کند
• اگر خواستی ربات را آپدیت کنی: فایل‌های جدید را در ریپو Commit کن؛
  Actions خودش بیلد می‌کند؛ بعد در ClawCloud دکمهٔ Restart/Redeploy
